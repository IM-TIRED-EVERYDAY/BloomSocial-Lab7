BloomSocial - Lab 7

Project Overview
BloomSocial is a social networking web application developed as a final exam project for the Spring Boot course. The platform allows users to create profiles, share posts, upload images, like posts, and communicate through comments.
Team Members
- Arysbekkyzy Uasilya - Backend Developer
- Amankos Aikorkem - Frontend & UX/UI Developer

Both team members participate in database design, integration, and testing.

Main Features
- User registration and login
- User profiles and profile editing
- Creating and deleting posts
- Uploading images
- Liking and commenting on posts
- Viewing the news feed
- Searching for users

Technology Stack
- Java 21
- Spring Boot
- Spring MVC
- Spring Security
- Spring Data JPA
- PostgreSQL
- Thymeleaf
- HTML, CSS, JavaScript
- Maven

Application Architecture
Frontend → Controller → Service → Repository → PostgreSQL Database
